# 마이웨이 75 · 코인 시그널 V1.14

Upbit KRW 12종목의 MACD·RSI 백테스트, MACD 1·2·3 자산곡선 비교, 최근 20봉 유사 패턴 분석을 제공하는 정적 웹 앱입니다.

MACD 3은 MACD(18,39,9)를 사용하며, MACD 2와 동일하게 0선 위·아래와 골든/데드크로스 조합에 따라 보유 비중을 100%·50%·0%로 조절합니다.

## 현물·선물 앱 분리

- `/`: 기존 현물 투자 앱
- `/futures/`: 선물 투자 앱. 초기 시그널은 현물과 동일하며 향후 선물 전용 백테스트 규칙을 독립적으로 추가합니다.
- 사용자 저장 전략과 검색 이력은 현물·선물 앱이 서로 다른 브라우저 저장 키를 사용합니다.

V1.07부터 수익률·최대낙폭 비교 차트는 각 코인 안에서 MACD 1·2·3이 연속으로 배치되어 전략 차이를 바로 비교할 수 있습니다.

V1.08부터 수익률 비교 차트에서 시작 연도와 종료 연도를 선택해 여러 해에 걸친 누적수익률을 비교할 수 있습니다.

V1.09부터 좌우 수익률·최대낙폭 차트의 머리글, 코인 행, 그룹 높이를 동기화해 같은 코인이 동일한 세로 위치에 표시됩니다.

V1.10부터 선물 투자 모드에 MACD 4가 추가됩니다. MACD(18,39,9)를 기준으로 0선 위·골든은 롱 100%, 0선 위·데드는 롱 50%, 0선 아래·골든은 롱 50%, 0선 아래·데드는 1배 숏 100%를 적용합니다. 전일 확정 상태를 다음 일봉 시가에 적용하고 수수료 0.05%와 슬리피지 0.08%를 반영합니다. 펀딩비·증거금·강제청산 가격은 아직 반영하지 않습니다.

V1.12부터 선물 투자 모드의 MACD 5는 MACD(18,39,9)가 0선을 상향돌파한 뒤 첫 골든크로스부터 다음 데드크로스 또는 0선 이탈 전까지만 롱 2배를 사용합니다. 나머지 구간은 MACD 4와 동일하게 0선 위·골든 롱 1배, 0선 위·데드 및 0선 아래·골든 롱 50%, 0선 아래·데드 숏 1배를 적용합니다. 일봉 시가·고가·저가·종가에서 계좌 가치가 0 이하가 되면 청산 처리합니다. 재계산 결과 MACD 5는 12종목 모두 비청산입니다.

V1.13부터 선물 투자 앱은 MACD 1~5 전략만 제공합니다.

V1.14부터 선물 투자 앱에 다중 시간봉 시뮬레이터를 추가합니다. BTC·ETH 등 12개 코인에서 일봉·4시간봉·1시간봉과 최근 200·500·1,000·2,000봉을 선택해 MACD 1~5의 누적수익률, 최대낙폭, 최종 자산, 포지션 변경 횟수와 현재 보유 상태를 같은 조건으로 비교할 수 있습니다. 확정 봉의 신호를 다음 봉 시가에 적용하고 수수료 0.05%와 슬리피지 0.08%를 반영합니다.

## 주요 화면

- `index.html`: 전체 코인 전략 수익률·MDD·자산곡선 비교
- `BTC-MACD-RSI-V2.3-ALL.html` 등: 12개 코인별 봉차트와 보조지표·유사 패턴 분석
- 최신 자료 버튼: Supabase Edge Function을 통해 12종목의 누락 구간을 증분 동기화

## 데이터·보안

- Supabase 프로젝트의 공개용 키만 브라우저에 포함됩니다.
- 데이터 쓰기는 Supabase Edge Function에서 처리하며 `service_role` 키는 저장소와 브라우저에 포함하지 않습니다.
- `coin_market_candles` 테이블에는 RLS가 활성화되어 있습니다.

## 주의

백테스트와 유사 패턴 확률은 과거 데이터 기반 통계이며 실제 수익이나 미래 가격을 보장하지 않습니다.
