PC가 켜져 있을 때 매매 관리

실행기 연결 확인 중…

전체 분석 앱 열기 · 비트코인 차트 · 처음 설정하는 순서

PC 종료·절전·인터넷 끊김 시 앱은 주문을 관리할 수 없습니다. 비트겟에 이미 접수된 주문은 PC가 꺼져도 체결될 수 있고, 보유 포지션과 청산 위험도 유지됩니다.

관리자 접속 후 이용하세요. 이 버튼은 보유 포지션을 청산하거나 Windows를 종료하지 않습니다.

처음 설정하는 순서

1. PC 실행 및 설정 파일 열기

앱 폴더의 PC-Start.cmd를 두 번 클릭합니다. 현재 PC에는 Node.js가 설치되어 있습니다. 다른 PC에서는 Node.js 24 LTS 이상을 먼저 설치하세요.

PC-Settings.cmd를 실행하면 이 PC의 비밀 설정 파일이 메모장으로 열립니다. API 키는 이 파일에만 입력합니다. 채팅·공유 드라이브·GitHub에 올리지 마세요.

실행 창을 닫으면 서버도 멈춥니다. 브라우저만 닫으면 서버는 계속 실행됩니다. 컴퓨터 로그인 시 자동 시작하지 않습니다.

2. 비트겟 계좌 유형과 USDT 선물 잔고 확인

현재 주문 엔진은 UTA 통합계좌 / USDT 무기한 / 단방향 / 격리 / 거래소 레버리지 2배에 맞춰져 있습니다. 클래식 계좌는 현재 이 실행기의 주문 대상이 아닙니다. USDT 환전은 계좌 유형 변경과 별개입니다.

앞서 보낸 화면에 통합계좌 업그레이드 안내가 있으므로, 유형을 확인하기 전 실거래를 켜지 마세요. 보유 포지션이 있는 계좌의 유형·포지션 모드를 임의로 전환하지 않습니다. USDT가 선물 거래에 사용 가능한 잔고인지 비트겟에서 확인합니다.

3. API 키 발급 및 PC의 인터넷 IP 등록

비트겟 API 관리에서 조회 및 UTA 거래 권한이 있는 키를 만듭니다. 출금 권한은 사용하지 않습니다. API Key, Secret, Passphrase 세 값을 PC 설정에 입력합니다. 데모는 데모 모드에서 별도로 발급한 키를 사용합니다.

허용 IP에는 PC의 인터넷 공인 IP를 등록합니다. 127.0.0.1이나 192.168.x.x는 등록할 주소가 아닙니다. 집 인터넷 재연결·공유기 교체 등으로 공인 IP가 바뀌면 허용 IP도 다시 확인해야 합니다. 포트 포워딩은 필요 없습니다.

BITGET_API_KEY=여기에_API_Key
BITGET_API_SECRET=여기에_Secret
BITGET_PASSPHRASE=여기에_Passphrase

실제 값을 따옴표로 감싸 저장하면 # 등 설정 구분 문자를 포함한 값도 보존할 수 있습니다. 값을 입력한 후 저장하고 실행기를 다시 시작합니다.

4. 데모로 먼저 연결
TRADING_ENABLED=true
BITGET_DEMO=true
BITGET_LIVE_ENABLED=false

PC 설정 파일의 TRADE_OPERATOR_TOKEN 오른쪽 값을 복사해 위 거래 관리의 실행 서버 연결 · 자동매매 관리 → 관리자 접속 토큰에 붙여 넣고 접속을 누릅니다. API Key를 넣는 칸이 아닙니다.

  1. 사용할 종목·전략을 선택합니다. 실행 전략은 MACD 1~5이며 완성 일봉 기준입니다.
  2. 계좌 전체·종목별 한도를 입력하고 한도 저장을 누릅니다. 한도는 증거금이 아니라 포지션 명목금액(USDT)입니다.
  3. 실계좌 잔고로 미리보기에서 데모 계좌 잔고·계좌 모드·주문 수량을 확인합니다. 이 단계는 주문을 보내지 않습니다.
  4. 이 거래소 자동매매 ON을 누른 뒤, 미리보기를 다시 만들고 거래소 데모 자동매매 시작을 누릅니다. 미리보기는 30초 후 만료됩니다.
  5. 비트겟 데모 주문·체결 내역과 앱 실행 상태를 비교합니다. 중지·미체결 취소도 확인합니다.

다른 수동 주문이나 봇과 같은 종목을 동시에 운용하면 충돌할 수 있습니다. 기존 미체결 때문에 미리보기가 거절될 때는 비트겟에서 상태부터 확인하세요.

5. 실거래로 전환 — 사용자가 직접 시작

먼저 데모를 전체 OFF하고 취소 완료를 확인한 다음 실행기를 종료합니다. PC 설정 파일에서 키 세 개를 본인의 실거래 키로 바꾸고 다음을 저장합니다.

TRADING_ENABLED=true
BITGET_DEMO=false
BITGET_LIVE_ENABLED=true

실행기를 다시 열고 접속 → 한도 저장 → 실계좌 미리보기 → 자동매매 ON → 새 미리보기 → 실주문 자동매매 시작을 직접 누릅니다. 시작 시 현재 신호에 맞춘 주문이 발생할 수 있습니다. 투입 금액과 전략은 사용자가 선택하며, 과거 확률은 수익 보장이 아닙니다.

계좌 권한·실제 체결은 키 연결 후 검증해야 합니다. 현재 키를 넣지 않은 설치 상태만으로 실거래가 검증된 것은 아닙니다.

6. 매일 실행·종료하는 방법
  1. PC-Start.cmd 실행 → 접속합니다. 매번 자동매매 OFF로 시작합니다.
  2. 이전 미체결 정리가 끝났는지 확인하고, 새 미리보기로 원하는 종목만 다시 시작합니다.
  3. PC를 끄기 전 위의 미체결 취소 확인 후 PC 실행기 종료를 누릅니다. 실패가 나오면 PC를 끄기 전에 비트겟에서 주문을 확인합니다.

강제 종료·정전 시 취소는 보장되지 않습니다. 다음 실행에서 이전 앱 주문의 취소를 다시 확인합니다. 절전이나 실행 지연을 감지하면 OFF로 전환합니다. 자동매매 중에는 Windows 전원 설정에서 절전 시간을 직접 확인하세요. 화면만 꺼지는 것은 절전과 다릅니다.

주문 기록은 server/data/pc-trading.sqlite에 보관합니다. 실행 중 삭제하거나 클라우드 동기화 폴더로 옮기지 마세요. 중복 실행은 원장 잠금 또는 포트 점유로 차단됩니다.
